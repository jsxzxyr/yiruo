# User Experience Direction

## First screen

The first screen offers New task, Recent tasks, and local knowledge bases. New
task choices are Document processing, Official writing, Web research, File
comparison, and Data analysis. These are workflow names, not implementation
names.

## Document-to-report journey

```text
choose Word/PDF -> describe desired report -> see privacy/data summary
-> local analysis -> facts/data/entities/structure review
-> generate draft -> edit and validate -> export DOCX/PDF after confirmation
```

The user can see which files and sources informed a paragraph. A blocked action
is explained in plain language and offers a local-only or redacted alternative.
No background upload, invisible provider switch, or silent overwrite is allowed.

## Interaction requirements

Use clear file pickers, review steps, progress states, cancel controls, and
undo/restore where an operation changes a file. Show model/provider and token
details only in the disclosure or professional panel. Confirm external sharing,
batch processing, expensive models, shell/MCP use, deletion, overwrite, and
export.
