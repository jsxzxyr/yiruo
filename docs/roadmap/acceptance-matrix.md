# Phase Acceptance Matrix

| Area | Phase 0 deliverable | Later acceptance condition |
|---|---|---|
| Provider | Real call paths and bypasses documented | One Gateway path; keys never reach agent/UI/logs |
| MCP | Transport, sampling, process, and data risks documented | Registry, scoped capabilities, policy before call |
| Files | IPC, shell, session, diagnostics paths documented | Canonical workspace roots and isolated workers |
| Network | Current provider/MCP/shell/auxiliary egress inventoried | Adapter allowlists and private-address protection |
| Storage | SQLite raw-content fields and exports documented | Encrypted opt-in sensitive retention, metadata audit |
| Tokens | Current usage/compaction and limits documented | Atomic task/provider/day/month budgets |
| Documents | Parser/model boundary specified | Deterministic parsing, chunking, provenance, validation |
| UX | Ordinary-user and professional-mode split specified | Reviewable disclosure and confirmation flows |
| Security | Threats, controls, residual risks recorded | Automated negative tests and release review |
